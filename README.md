# 血糖记录 · GlucoLog

单文件血糖记录网站，为 2 型 / 血糖偏高人群设计。无后端、无依赖，血糖数据全部保存在本机浏览器（localStorage），双击 `index.html` 即可使用。

## 功能

- **今日**：最近读数、今日统计、服药打卡、近 7 天对比、备份提醒
- **快速录入**：大数字键盘、单位切换（mmol/L ↔ mg/dL）、时段与情景标签、补录
- **记录**：按天分组的时间线，支持按时间 / 时段 / 达标状态筛选，可编辑、删除
- **趋势**：全部读数折线图（空腹目标带、餐后上限线、低血糖线）、空腹 / 餐后每日均值分图、时段 × 星期热力图
- **报告**：测量次数、达标率、空腹 / 餐后均值、低血糖次数、服药打卡率；本地智能分析；可选 AI 深度解读（自带 API Key，直连大模型分析数据摘要）；可打印 / 另存为 PDF、导出 CSV
- **问诊**：医学问诊聊天页。浏览器先在本地检索 `med-kb.json`（8 千条中文医患问答），再经 Cloudflare Worker 转发 DeepSeek 生成回答；API Key 只存在 Worker 密钥里，网页代码不含 Key
- **我的**：单位与目标、个人资料、体重 / HbA1c / 血压、AI 分析设置、AI 问诊设置、数据备份与恢复、指标解释
- 离线可用；支持浅色 / 深色主题

## 使用方法

**方式一：本地直接打开**
把 `index.html` 下载到电脑或手机，双击用浏览器打开即可（无需服务器）。

**方式二：部署到 GitHub Pages**
1. 新建 GitHub 仓库，把本目录文件上传到仓库根目录（`index.html`、`README.md`、`worker.js`，以及可选 `med-kb.json`）
2. 进入仓库 **Settings → Pages**
3. Source 选 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`，点 Save
4. 稍等片刻，访问 `https://<用户名>.github.io/<仓库名>/`

## 启用「问诊」页（方案二）

1. cloudflare.com → Workers 和 Pages → 创建 Worker → 粘贴本仓库 `worker.js` → 部署
2. Worker → 设置 → 变量和机密 → 添加密钥：名称 `DEEPSEEK_API_KEY`，值 = 你的 DeepSeek API Key；（可选）再加 `ALLOW_ORIGIN` = 你的网站域名，限制调用来源
3. 把 `med-kb.json`（浏览器版小知识库，约 13 MB）放到本页同目录并上传
4. 打开网站 →「我的」→「AI 问诊」→ 填入 Worker 网址（如 `https://xxx.workers.dev`）
5. 打开「问诊」页提问验证

## 数据与隐私

- 血糖等记录只存在浏览器 localStorage，不上传任何服务器。
- 「报告 → AI 深度解读」需要自行填写 API Key：Key 只存在本机浏览器，数据会上传到你选择的 AI 服务商，按用量计费；不要在公共电脑上使用。
- 「问诊」页不接触 API Key（Key 只在 Cloudflare Worker 密钥里），但问题内容会发送给 Worker 和 DeepSeek。
- 换设备、清除浏览器数据会丢失记录：请定期在「我的 → 导出备份」导出 JSON 文件。
- iOS Safari 可能清理长期未访问网页的本地数据，备份提醒会在首页提示。

## 默认目标范围

参考中国 2 型糖尿病防治指南：空腹 4.4–7.0 mmol/L、餐后 2h <10.0 mmol/L、低血糖 ≤3.9 mmol/L（餐后从吃第一口饭计时）。请在「我的」中按医生建议修改。
